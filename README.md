# Arena Tech - Planejador de Maratona Gamer 🎮

Projeto desenvolvido em linguagem C para calcular os custos e organizar uma maratona gamer na faculdade.

## Como funciona?

O programa solicita algumas informações sobre o evento, como:

* Quantidade de participantes;
* Quantidade de jogadores por time;
* Número de computadores;
* Potência dos computadores;
* Duração do evento em horas;
* Preço do kWh de energia;
* Preço do kit de alimentação por participante;
* Outros custos do evento.

Com esses dados, o programa calcula a quantidade de times necessários, o consumo de energia, o custo da energia, o custo da alimentação, o custo total e o valor médio por participante.

No final, os resultados são apresentados na tela em forma de relatório.

## Tecnologias utilizadas

* Linguagem C
* Biblioteca `stdio.h`
* Entrada de dados com `scanf()`
* Saída de dados com `printf()`
* Operações matemáticas

## Objetivo

Praticar os conceitos básicos de programação em C, utilizando variáveis, entrada e saída de dados e operações aritméticas para resolver um problema do cotidiano.
